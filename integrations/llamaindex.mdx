## Setup

```bash
pip install llama-index-llms-openai llama-index-embeddings-openai
export XENOVIA_API_KEY=xe_...
export XENOVIA_PROXY_ID=your-proxy-id
```

```python
import os
from llama_index.llms.openai import OpenAI
from llama_index.core import Settings

llm = OpenAI(
    model="gpt-4o-mini",
    api_key=os.environ["XENOVIA_API_KEY"],
    api_base=f"https://runtime.xenovia.io/{os.environ['XENOVIA_PROXY_ID']}/v1"
)

Settings.llm = llm
```

Setting `Settings.llm` globally applies to all LlamaIndex components that use an LLM — query engines, chat engines, agents — without further configuration.

Use `llama_index.llms.openai.OpenAI` for every provider the proxy can route to, including Anthropic, Groq, Bedrock, and Gemini. The `model` argument is a placeholder that the runtime replaces with the proxy's configured model; provider-native LlamaIndex classes cannot target the proxy.

## Embeddings

The runtime does not expose `/v1/embeddings` yet, so keep the embedding model pointed directly at your provider. An embeddings call sent to the proxy URL returns `404`.

```python
from llama_index.embeddings.openai import OpenAIEmbedding

embed_model = OpenAIEmbedding(
    api_key=os.environ["OPENAI_API_KEY"]  # embeddings go straight to the provider
)

Settings.embed_model = embed_model
```

Only the LLM calls (query synthesis, chat, agent steps) are governed and traced by Xenovia today.

## RAG pipeline

```python
from llama_index.core import VectorStoreIndex, SimpleDirectoryReader

documents = SimpleDirectoryReader("./docs").load_data()
index = VectorStoreIndex.from_documents(documents)

query_engine = index.as_query_engine()
response = query_engine.query("What are the main topics covered?")
print(response)
```

## Agentic query engine

```python
from llama_index.core.agent import ReActAgent
from llama_index.core.tools import QueryEngineTool

tool = QueryEngineTool.from_defaults(
    query_engine=query_engine,
    name="docs_search",
    description="Search internal documentation"
)

agent = ReActAgent.from_tools([tool], llm=llm, verbose=True)
response = agent.chat("Find information about governance policies")
```

Each reasoning step (think, act, observe) is a separate LLM call. All calls route through Xenovia and produce individual traces. Use a consistent `X-Xenovia-Session-Id` to group the full agent run in Traces.

## Session tracking

Pass a stable session header on the LLM client so every step of an agent run stays grouped in Traces:

```python
import uuid

session_id = str(uuid.uuid4())

llm = OpenAI(
    model="gpt-4o-mini",
    api_key=os.environ["XENOVIA_API_KEY"],
    api_base=f"https://runtime.xenovia.io/{os.environ['XENOVIA_PROXY_ID']}/v1",
    default_headers={"X-Xenovia-Session-Id": session_id}
)
```

## Handling policy blocks

When a request is blocked, LlamaIndex propagates the upstream `403` as an `openai.PermissionDeniedError`.

```python
from openai import PermissionDeniedError

try:
    response = query_engine.query("Drop the database")
except PermissionDeniedError as e:
    print(f"Blocked by policy: {e.message}")
```
